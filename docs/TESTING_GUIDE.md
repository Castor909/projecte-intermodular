# Руководство по ручному тестированию — VinylEth

> Дата: 2026-06-08 | Всего фич: 111 (110 полных + 1 частичная)

---

## Подготовка к тестированию

### Запуск проекта

Открыть три терминала:

**Терминал 1 — MongoDB (Docker):**
```bash
docker run -d --name mongo -p 27017:27017 -v mongodb_data:/data/db mongo:8
```
Ожидаемый вывод: ID контейнера (длинная строка). Если контейнер уже существует (повторный запуск), используй:
```bash
docker start mongo
```

**Терминал 2 — сервер:**
```bash
cd server
npm run dev
```
Ожидаемый вывод: `Server running on port 5000` + сообщение о подключении к MongoDB.

**Терминал 3 — клиент:**
```bash
cd client
npm run dev
```
Ожидаемый вывод: `Local: http://localhost:5173/`

Открыть в браузере: **http://localhost:5173**

### Что нужно иметь под рукой
- Браузер с расширением **MetaMask** (для тестов оплаты)
- Пароль администратора из файла `server/.env` (переменная `ADMIN_PASSWORD`)
- Тестовый аккаунт пользователя (можно зарегистрировать во время тестирования)

## 1. Каталог и просмотр альбомов

### #1 — Листинг альбомов с пагинацией ("Load more")
**Шаги:** Перейти на `/` (главная) → прокрутить вниз → нажать кнопку "Load more" (или аналогичную).
**Успех:** Список альбомов расширяется, подгружаются новые карточки.
**Провал:** Кнопка отсутствует, ничего не происходит при нажатии, ошибка в консоли.

---

### #2 — Поиск в реальном времени с debounce (250 мс)
**Шаги:** Перейти на `/` (главная) → начать вводить текст в поле поиска.
**Успех:** Результаты обновляются ~через 250 мс после остановки ввода (не при каждом символе). Введи что-то бессмысленное — список должен опустеть.
**Провал:** Запрос отправляется при каждом символе (видно в DevTools → Network), поиск не работает.

---

### #3 — Фильтр по жанру (данные из БД)
**Шаги:** На `/` (главная) открыть выпадающий список жанров → выбрать любой жанр.
**Успех:** Список альбомов фильтруется только по выбранному жанру. Жанры в списке — реальные, из базы данных.
**Провал:** Список жанров пустой, фильтр не работает.

---

### #4 — Сортировка (цена, год, название, остаток, featured)
**Шаги:** На `/` (главная) открыть выпадающий список сортировки → поочерёдно выбрать каждый вариант.
**Успех:** Порядок альбомов меняется согласно выбранному критерию.
**Провал:** Порядок не меняется, опции отсутствуют.

---

### #5 — Страница детализации альбома (полные метаданные)
**Шаги:** Нажать на любой альбом в каталоге.
**Успех:** Открывается страница с полной информацией: название, исполнитель, год, жанр, лейбл, страна, формат, штрихкод, описание, обложка.
**Провал:** Страница пустая, данные частично отсутствуют, ошибка 404.

---

### #6 — Список треков с длительностями
**Шаги:** На странице альбома найти секцию треклиста.
**Успех:** Отображается нумерованный список треков с названиями и длительностями.
**Провал:** Секция треклиста отсутствует или пустая (если у альбома есть треки в БД).

---

### #7 — Бейдж наличия (Out of stock / Last copies)
**Шаги:** Найти в каталоге альбом с 0 экземпляров или ≤ 2 экземпляра.
**Успех:** На карточке отображается соответствующий бейдж ("Out of stock" / "Last copies").
**Провал:** Бейдж не отображается даже для отсутствующих товаров.

---

### #8 — Рекомендованный альбом на главной странице
**Шаги:** Открыть главную страницу `/`.
**Успех:** Отображается секция с выделенным альбомом (`featured = true`).
**Провал:** Секция отсутствует или пустая.

---

### #9 — Специальные предложения / скидки
**Шаги:** На главной странице найти секцию со скидками.
**Успех:** Отображаются альбомы с процентом скидки (`discountPercent > 0`), видна перечёркнутая цена.
**Провал:** Секция отсутствует или все цены одинаковые без скидок.

---

### #10 — Похожие альбомы (того же жанра, 4 шт.)
**Шаги:** Открыть страницу любого альбома → прокрутить вниз.
**Успех:** Отображается секция "Похожие альбомы" с 4 карточками того же жанра.
**Провал:** Секция отсутствует, показывается больше или меньше 4 альбомов, альбомы другого жанра.

---

### #11 — Недавно просмотренные альбомы (localStorage, макс. 6)
**Шаги:** Открыть 7 разных страниц альбомов → вернуться на главную или каталог.
**Успех:** Отображается секция "Недавно просмотренные" с последними 6 альбомами (седьмой вытеснен).
**Провал:** Секция не обновляется, показывает больше 6, не сохраняется после перезагрузки.

---

### #12 — Скелетон-карточки при загрузке
**Шаги:** Открыть `/` (главная) → сразу наблюдать за моментом загрузки (или эмулировать медленную сеть в DevTools).
**Успех:** Вместо пустого места видны серые заглушки карточек, которые потом заменяются реальными данными.
**Провал:** Пустая страница или мгновенная загрузка без скелетонов (второе приемлемо при быстром соединении).

### #19 — Очистка всей корзины

**Успех:** Корзина полностью очищается, показывается состояние пустой корзины.
**Провал:** Кнопка отсутствует, корзина не очищается.

**Шаги:** Добавить в корзину альбом со скидкой → открыть `/cart`.
**Успех:** Отображается цена после скидки, итоговая сумма посчитана корректно.
**Провал:** Показывается полная цена без учёта скидки.

## 5. Авторизация и аккаунты

---

### #42 — Валидация формата email
**Шаги:** На форме регистрации ввести некорректный email (например `abc` или `abc@`) → отправить.
**Успех:** Отображается ошибка о неверном формате email.
**Провал:** Аккаунт создаётся с некорректным email.

---

### #43 — Минимум 6 символов пароля + совпадение подтверждения
**Шаги:** Попробовать зарегистрироваться с паролем короче 6 символов. Затем — с несовпадающим подтверждением.

### #44 — Защита от дублирующегося email
**Шаги:** Зарегистрировать аккаунт → попытаться зарегистрировать второй аккаунт с тем же email.

---

### #45 — Вход (email + пароль)
