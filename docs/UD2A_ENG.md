## Unit Context and Objective
This unit corresponds to the advanced development phase of the project.
After completing the initial phase (UD1A) and its consolidation (UD1B), the objective of UD2A is to:

- Continue developing the project.
- Improve technical and functional quality.
- Refine structure and organization.
- Professionalize documentation.

The project should begin to look like a real product in development, not an academic exercise.

## Tasks to Complete
### 1. Advanced Development
- Expand existing features.
- Incorporate new features.
- Improve system integration.
- Reduce the use of mocks.

### 2. Technical and Structural Improvement
- Code refactoring.
- Architecture improvement.
- Separation of responsibilities.
- Basic optimization.

### 3. Real Project Management
- Updated Trello board.
- Real tasks (not decorative).
- Continuous tracking.
- Planning adjustments.

### 4. Professional Documentation (MANDATORY)
Documentation:
- Must be updated to match the code.
- Must explain real system behavior.
- Must include:
  - Own technical decisions.
  - Problems encountered.
  - Applied solutions.
  - Project evolution.

It must be understandable by an external person.

## Mandatory Condition
A submission without updated documentation will be considered incomplete and WILL NOT be evaluated.

## Technical Defense
The student must be able to explain:
- What they have done.
- How it works.
- Why it was done this way.

## Deliverables
- Updated GitHub repository.
- Project documentation (PDF or Markdown).
- Updated Trello board.
- Functional demonstration.
