# VinylEth — Полный обзор функциональности

**VinylEth** — интернет-магазин виниловых пластинок с оплатой в ETH (Ethereum). Покупатель просматривает каталог, добавляет товары в корзину, вводит адрес доставки и оплачивает заказ через MetaMask.

---

## Технический стек

| Слой | Технологии |
|---|---|
| Frontend | React 19, React Router v7, Vite (rolldown-vite) |
| Backend | Node.js, Express 5, MongoDB (Mongoose 9) |
| Блокчейн | MetaMask / `window.ethereum` (EIP-1193) |
| Сборка | Vite + ESLint |

---

## Функциональность по блокам

### 1. Каталог (`/`)

**Главный банер (Featured Album)**
- Показывает первый альбом из списка в виде hero-секции с обложкой, исполнителем, ценой и кнопкой «Buy Now».

**Специальные предложения (Special Offers)**
- Секция с карточками альбомов, у которых выставлен флаг `featured: true` в базе данных.
- На каждой карточке — бейдж «Featured», обложка, исполнитель, название, цена и кнопка перехода.

**Сетка каталога (New Arrivals)**
- Отображает все альбомы из базы в виде адаптивной сетки карточек.
- Показывает счётчик результатов («N results»).
- Если нет совпадений — показывает empty-state с подсказкой.

**Поиск**
- Поиск по полям: название, исполнитель, жанр.
- Поиск нечувствителен к регистру.
- Работает в реальном времени (без кнопки отправки).

**Фильтр по жанру**
- Выпадающий список жанров, который формируется динамически из данных в БД.
- Вариант «All genres» всегда доступен.

**Сортировка**
- Featured first — помеченные альбомы идут первыми (по умолчанию)
- Title A-Z / Title Z-A
- Price low→high / Price high→low
- Newest first / Oldest first (по году выпуска)
- Stock high→low (по количеству на складе)

---

### 2. Детальная страница альбома (`/album/:id`)

**Основная информация**
- Обложка (240×240 px), название, исполнитель, год, жанр, описание.
- Количество на складе (`stock`).
- Цена в ETH (выделена оранжевым).

**Добавление в корзину**
- Кнопка «Add to Cart» добавляет альбом в глобальную корзину.
- Если `stock ≤ 0` — кнопка переходит в состояние «Out of Stock» и блокируется.
- После добавления показывается inline-сообщение об успехе.
- Если товар уже добавлен в максимально доступном количестве — появляется предупреждение.

**Vinyl specs (технические данные пластинки)**
- Блок отображается только если данные есть: Format, Label, Country, Barcode.
- Данные обогащаются через скрипт MusicBrainz (см. раздел «Инструменты разработчика»).

**Список треков (Tracklist)**
- Отображается нумерованный список треков с названием и длительностью.
- Блок скрыт, если трекбист не задан.

**Навигация**
- Кнопка «← Back» возвращает на предыдущую страницу.

---

### 3. Корзина (`/cart`)

**Список товаров**
- Каждый элемент: обложка (60 px), название, исполнитель, управление количеством, цена за позицию, кнопка «Remove».
- Кнопка «+» заблокирована, когда количество достигло лимита склада.
- Под элементом показывается доступный остаток (`Available: N`).

**Управление количеством**
- «+» — увеличить на 1 (с проверкой стока).
- «-» — уменьшить на 1; при qty=1 удаляет товар из корзины.

**Итог**
- Общая сумма в ETH с точностью до 3 знаков.

**Действия**
- «Clear Cart» — очищает всю корзину.
- «Proceed to Checkout →» — переходит на форму доставки.

**Персистентность**
- Корзина сохраняется в `localStorage` (`key: cart`) и восстанавливается при обновлении страницы.

---

### 4. Форма доставки (`/checkout/shipping`)

**Индикатор шагов**
- Cart › **Shipping** › Payment — текущий шаг выделен.

**Поля формы**
- Full name, Address, City, Postal code, Country.

**Валидация**
- Все поля обязательны; ошибки показываются inline под полем.
- Валидация происходит при попытке отправки формы.
- Ошибка поля сбрасывается при изменении его значения.

**Персистентность**
- Данные формы сохраняются в `localStorage` (`key: vinyleth_shipping`).
- При повторном заходе форма автоматически заполняется сохранёнными данными.

**Навигация**
- «← Back to cart» — возврат в корзину.
- «Continue to payment →» — переход на страницу оплаты.

---

### 5. Оплата (`/checkout/payment`)

**Индикатор шагов**
- Cart › Shipping › **Payment** — текущий шаг выделен.

**Сводка заказа**
- Список товаров: название × количество = цена в ETH.
- Итоговая сумма.

**Адрес доставки**
- Показывает данные, введённые на предыдущем шаге.
- Кнопка «Edit» возвращает на форму доставки.

**Оплата через MetaMask**
- Кнопка «Pay now» инициирует ETH-транзакцию через `window.ethereum`.
- Сумма конвертируется из ETH в wei через `BigInt` (без потери точности из-за float).
- Транзакция отправляется на кошелёк магазина (`STORE_WALLET` из `config/payment.js`).

**Состояния кнопки оплаты**
- `idle` — «Pay now»
- `waiting` — «Waiting for MetaMask...» (кнопка заблокирована)
- `submitted` — экран успеха
- `error` — сообщение об ошибке

**Экран успеха**
- Заголовок «Order placed!».
- Отображается хэш транзакции (`txHash`).
- Корзина очищается автоматически.
- Кнопка «Back to catalog».

**Обработка ошибок**
- MetaMask не установлен → «MetaMask is not installed.»
- Пользователь отклонил транзакцию (код 4001) → «Transaction rejected.»
- Прочие ошибки → сообщение из `err.message`.
- `STORE_WALLET` не задан → предупреждение с инструкцией по настройке.

### 6. Шапка сайта (Header)

**Логотип и навигация**
- Логотип «VinylEth».
- Ссылки: Catalog (`/`), Cart (`/cart`), About, Contact (заглушки).

**Подключение MetaMask-кошелька**
- Кнопка «Connect wallet» — запрашивает доступ к аккаунту через `eth_requestAccounts`.
- При наличии активной сессии MetaMask — адрес подставляется автоматически без дополнительного запроса.
- Подключённый адрес отображается в усечённом виде: `0x1234...5678`.
- Кнопка «Disconnect» — отключает кошелёк на стороне приложения.
- Реагирует на событие `accountsChanged` (переключение аккаунта в MetaMask).
- Повторная инициализация провайдера через событие `ethereum#initialized` и таймаут 700 мс (для поздней загрузки расширения).

### 7. Панель администратора (`/admin`)

**Вход (`/admin/login`)**
- Форма с полем пароля; пароль задаётся в `server/.env` (`ADMIN_PASSWORD`).
- При успешном входе токен сохраняется в `localStorage` (`admin_token`).
- Неверный пароль — inline-сообщение об ошибке без перезагрузки страницы.
- Главный Header магазина на admin-страницах скрыт (отдельный layout).

**Защита маршрута (`AdminGuard`)**
- Если токен отсутствует в `localStorage` — автоматический редирект на `/admin/login`.
- При получении 401 от API токен очищается и происходит редирект на логин.

**Список альбомов**
- Таблица с колонками: обложка (48×48 px), название, исполнитель, жанр, цена (ETH), сток, флаг Featured, кнопки действий.
- Данные загружаются через тот же публичный `GET /api/albums`.
- Счётчик «Albums (N)» в заголовке.

**Создание альбома (+ Add Album)**
- Открывает форму. Обязательные поля: Title, Artist, Year, Genre, Price (ETH), Cover URL, Stock, Description.
- Опциональные поля: Featured (checkbox), Audio URL.
- Секция «Vinyl Specs»: Label, Country, Format, Barcode.
- Секция «Tracklist»: динамический список строк (Track title + Duration); строки добавляются / удаляются кнопками.
- Превью обложки — живой `<img>` тег по введённому URL; скрывается при ошибке загрузки.
- Клиентская валидация: все обязательные поля, числовой формат year/priceEth/stock.
- После успешного сохранения новый альбом добавляется в начало таблицы без перезагрузки страницы.

**Редактирование альбома (Edit)**
- Та же форма, предзаполненная данными выбранного альбома.
- Треки из БД отображаются в виде отдельных строк.
- Кнопка «Save changes» отправляет `PUT /api/albums/:id`.
- Обновлённая запись мгновенно отражается в таблице.

**Удаление альбома (Delete)**
- Кнопка красного цвета; перед удалением показывает `window.confirm`.
- Отправляет `DELETE /api/albums/:id`.
- Альбом исчезает из таблицы без перезагрузки.

**Навигация**
- Кнопка «← Shop» возвращает на главную страницу магазина.
- Кнопка «Log out» очищает токен и редиректит на `/admin/login`.

## Бэкенд и база данных

### REST API

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| GET | `/api/albums` | — | Список всех альбомов |
| GET | `/api/albums/:id` | — | Один альбом по MongoDB ObjectId |
| POST | `/api/albums` | Admin | Создать новый альбом |
| PUT | `/api/albums/:id` | Admin | Обновить альбом |
| DELETE | `/api/albums/:id` | Admin | Удалить альбом |
| POST | `/api/admin/login` | — | Вход администратора, возвращает токен |

**Авторизация admin-маршрутов**
- Middleware `requireAdmin` проверяет заголовок `x-admin-token`.
- Токен сравнивается с `ADMIN_PASSWORD` из `server/.env`.
- При несовпадении — `401 Unauthorized`.

**Ответы на ошибки**
- `400 Bad Request` — невалидный формат id (`Invalid album id format`)
- `401 Unauthorized` — отсутствует или неверный admin-токен
- `404 Not Found` — альбом не найден (`Album not found`)
- `500 Internal Server Error` — централизованный обработчик ошибок

### Модель данных (Album)

| Поле | Тип | Описание |
|---|---|---|
| `title` | String | Название альбома |
| `artist` | String | Исполнитель |
| `year` | Number | Год выпуска |
| `genre` | String | Жанр |
| `priceEth` | Number | Цена в ETH |
| `coverUrl` | String | URL обложки |
| `stock` | Number | Количество на складе |
| `featured` | Boolean | Помечен как избранный |
| `description` | String | Описание |
| `audioUrl` | String | URL аудиопревью (необязательно) |
| `tracks` | Array | Список треков `{title, duration}` |
| `label` | String | Лейбл (от MusicBrainz) |
| `country` | String | Страна издания (от MusicBrainz) |
| `vinylFormat` | String | Формат: «12" Vinyl» и др. (от MusicBrainz) |
| `barcode` | String | Штрихкод (от MusicBrainz) |
| `mbid` | String | MusicBrainz Release ID |

### Автосид (seed)

- При первом запуске сервера (если коллекция пуста) в MongoDB автоматически загружаются 3 альбома:
  - **Dark Side of the Moon** — Pink Floyd, 1973, Progressive Rock, 0.05 ETH, stock: 5, featured
  - **Abbey Road** — The Beatles, 1969, Rock, 0.034 ETH, stock: 8
  - **Rumours** — Fleetwood Mac, 1977, Soft Rock, 0.04 ETH, stock: 6, featured

## Инструменты разработчика

### Обогащение данных MusicBrainz (`npm run enrich`)

- Скрипт `server/scripts/enrich-albums.js` обходит все альбомы в БД и запрашивает данные из [MusicBrainz API](https://musicbrainz.org/ws/2).
- Для каждого альбома ищет релиз по исполнителю и названию, предпочитая формат «12" Vinyl».
- Дополняет БД полями: `label`, `country`, `vinylFormat`, `barcode`, `mbid`.
- Соблюдает rate-limit: задержка 1200 мс между запросами.

### API contract-тесты (`npm test` — сервер)

- Скрипт `server/scripts/api-contract-check.js` проверяет:
  - `GET /api/albums` возвращает статус 200 и массив.
  - `GET /api/albums/abc` возвращает 400 с нужным сообщением.
  - `GET /api/albums/<несуществующий ObjectId>` возвращает 404.

### Unit-тесты корзины (`npm test` — клиент)

- Скрипт `client/scripts/cart-state-check.js` тестирует чистые функции корзины:
  - Добавление товара в пустую корзину.
  - Увеличение количества при повторном добавлении.
  - Блокировка превышения стока при добавлении и увеличении.
  - Уменьшение количества (qty=1 → удаление из корзины).
  - Отказ добавить out-of-stock товар.
  - Удаление конкретного товара из корзины.

## Управление состоянием корзины

- Глобальный контекст `CartContext` оборачивает всё приложение.
- Логика корзины вынесена в чистые функции (`cartState.js`) — без побочных эффектов.
- Доступные операции: `addToCart`, `removeFromCart`, `increaseQuantity`, `decreaseQuantity`, `clearCart`.
- Все операции возвращают `{ ok, message }` — компоненты могут показывать обратную связь.
- `cartNotice` — строка уведомления, которая отображается в корзине и на детальной странице.
